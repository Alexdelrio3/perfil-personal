# Outline de la Página Web - Alejandro Fernández del Río

## Estructura HTML

### 1. index.html - Página Principal
**Estructura general:**
- Header con navegación
- Sección Hero/Perfil
- Timeline académico
- Líneas de investigación
- Publicaciones destacadas
- Footer

### 2. publicaciones.html - Catálogo Completo
**Contenido:**
- Galería completa de publicaciones
- Sistema de filtros avanzados
- Búsqueda por palabras clave
- Detalles de cada publicación

### 3. proyectos.html - Proyectos de Investigación
**Contenido:**
- Proyectos actuales y finalizados
- Colaboraciones internacionales
- Estancias de investigación
- Resultados y impacto

## Recursos Necesarios

### Imágenes
- **Hero background**: Imagen abstracta académica
- **Perfil personal**: Foto profesional del investigador
- **Instituciones**: Logos de universidades
- **Proyectos**: Imágenes representativas de investigación

### Librerías JavaScript
- **Anime.js**: Animaciones y transiciones
- **ECharts.js**: Gráficos bibliométricos
- **p5.js**: Fondo con partículas animadas
- **Splide.js**: Carruseles de publicaciones

### Datos de Contenido
- Información personal completa
- Lista completa de publicaciones
- Datos bibliométricos
- Información de colaboraciones

## Flujo de Desarrollo

### Fase 1: Estructura Base
1. Crear HTML principal con navegación
2. Implementar sistema de rutas
3. Añadir estilos base con Tailwind

### Fase 2: Contenido Principal
1. Sección hero con información personal
2. Timeline académico interactivo
3. Galería de publicaciones

### Fase 3: Interactividad
1. Animaciones con Anime.js
2. Gráficos con ECharts.js
3. Efectos de scroll y hover

### Fase 4: Optimización
1. Responsive design
2. Optimización de imágenes
3. Pruebas de navegación
